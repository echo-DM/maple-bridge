# 浏览器验收

日期：2026-10-01。测试对象为本项目的实际开发页面与 `pnpm build` 生成的生产页面；文档截图来自生产预览。

## 环境与结果

- Node.js 26.7.0、pnpm 11.23.0；`pnpm check` 与 `pnpm build` 通过。
- agent-browser 0.32.4，Chrome for Testing 151.0.7922.47，macOS arm64。
- 桌面视口 1440×900、手机模拟视口 390×844。
- 约 48,687 个主场景方块，实例化渲染；典型视点约 100 次绘制调用、约 60 万个三角形。
- 桌面及模拟手机视口的实际帧率采样约 60 fps。该数值仅代表本机测试环境，不代表真实手机性能。
- 生产构建 JS 约 596 KB，gzip 约 152 KB。Vite 提示超过默认 500 KB 分块阈值；构建成功，未屏蔽该提示。

## 已检查的行为

| 检查 | 结果 |
| --- | --- |
| 首屏全景与四处诗境 | 全部正常显示；共有江流、桥、树、寺、远城与客船，切换过程中不替换世界。 |
| 景物与构图 | 月、霜岸与乌鸦可辨认；第二句可看到船头旅人；第三句可看见寺院与远城；第四句钟楼与客船同框。 |
| 诗句切换 | 按顺序游览与任意跳转均可抵达，标题和导航高亮一致；飞行视点避开建筑。 |
| 快速连续切换 | 以最终选择的诗句为准，不残留旧镜头动画。 |
| 重复输入回归 | 连续点击同一句 100 次并模拟重复按键，仍正常抵达；已加入界面及镜头两层保护。 |
| 自由环看与缩放 | 实际鼠标拖动改变方向；滚轮改变远近；输入立即中断运镜。 |
| 手机触控 | 通过本地测试浏览器的 CDP 模拟触摸：单指移动改变环看角度，两指外扩缩短观察距离。 |
| 手机布局 | 四个诗句按钮完整可见，无横向溢出；标题、诗境说明与沉浸按钮可用。 |
| 键盘与循环导航 | 标准 Digit1 键事件可抵达第一句，左右方向键切换；上一句、下一句在全景和四句之间循环。 |
| 沉浸模式 | 界面隐藏且不可聚焦，只保留恢复按钮；Esc 恢复界面。 |
| 减少动态效果 | 媒体偏好开启后直接抵达，`flying=false`，状态播报为“已抵达”；水面、落叶、乌鸦、船与钟声动态保持静止。 |
| 钟声视觉 | 镜头抵达第四句后钟摆与光晕开始；光晕从钟楼向客船传播并消散，不播放音频。 |
| WebGL 故障恢复 | 用 `WEBGL_lose_context` 强制丢失上下文后，显示重新加载提示，焦点移至按钮、其他控件不可聚焦；点击按钮后恢复全景，`ready=true`。 |
| 控制台 | 正常生产游览中未观察到页面异常或控制台错误。 |
